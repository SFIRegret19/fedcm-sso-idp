# FedCM SSO Identity Provider & Relying Party

Программный комплекс для реализации сервиса единого входа (Single Sign-On). Проект разработан с фокусом на современные требования веб-безопасности, микросервисную архитектуру и отказ браузеров от сторонних файлов cookie (инициатива Privacy Sandbox).

Система использует **гибридный подход** для обеспечения бесшовного пользовательского опыта:
1. **FedCM (Federated Credential Management API)** — новейший стандарт W3C для безопасной и приватной авторизации через нативные диалоговые окна браузера (без использования 3rd-party cookies).
2. **Classic Redirect Flow (OIDC)** — надежный резервный (fallback) механизм авторизации для первичного входа и поддержки браузеров без FedCM (Safari, Firefox, устаревшие версии).

## 🛠 Технологический стек

**Backend (Identity Provider - IdP):**
* **Python 3.13+** & **FastAPI** — высокопроизводительный асинхронный веб-фреймворк.
* **SQLAlchemy 2.0** — ORM для работы с базой данных (в прототипе используется SQLite).
* **PyJWT, bcrypt** — криптография, хеширование паролей и выпуск токенов.

**Frontend (Relying Party - RP):**
* **React 18** & **Vite** — создание быстрого одностраничного приложения (SPA).
* **Axios** — HTTP-клиент с настроенными интерцепторами для ротации токенов.
* Взаимодействие с нативным `navigator.credentials.get()`.

**Инфраструктура и Безопасность:**
* **mkcert** — локальный центр сертификации для развертывания полноценного HTTPS.
* **Refresh Token Rotation** — хранение долгоживущих токенов в защищенных `HttpOnly` cookie и использование краткосрочных JWT в оперативной памяти клиента (защита от XSS и CSRF).
* Реализация **Login Status API** (HTTP-заголовок `Set-Login`).

## 📁 Структура проекта

Проект разделен на два независимых сервиса для эмуляции реального кросс-доменного взаимодействия:
* `/backend` — сервер авторизации (IdP).
* `/frontend` — тестовое клиентское приложение (RP).

## ✨ Ключевые возможности

* **Умная маршрутизация входа:** Клиентский скрипт автоматически определяет возможности браузера и наличие сессии, предлагая нативное окно FedCM или классическую форму входа.
* **Управление пользователями:** Регистрация, авторизация, личный кабинет (изменение имени, email и безопасная смена пароля).
* **Современная безопасность:** Cross-Origin изоляция, строгие политики CORS, атрибуты `SameSite=None` и `Secure` для cookie.
* **Автодокументация API:** Встроенный Swagger UI доступен по адресу `/docs`.



## 🚀 Быстрый запуск (Локальная среда)

Поскольку FedCM требует строгого соблюдения политик Secure Context (HTTPS) и кросс-доменного взаимодействия, для запуска проекта необходимо настроить локальные домены.

### Шаг 1. Настройка локальных доменов (hosts)
Откройте файл `C:\Windows\System32\drivers\etc\hosts` (от имени Администратора) и добавьте две строки:
```text
127.0.0.1       idp.test
127.0.0.1       rp.test
```

### Шаг 2. Запуск Backend (IdP)
1. Установите утилиту [mkcert](https://github.com/FiloSottile/mkcert) и сгенерируйте сертификаты в папке `backend`:
   ```bash
   mkcert -install
   mkcert idp.test rp.test
   ```
2. Откройте терминал в папке `backend` и настройте виртуальное окружение:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` в папке `backend` и укажите секретный ключ:
   ```env
   JWT_SECRET=ваша_секретная_строка
   DATABASE_URL=sqlite:///./sso_database.db
   ```
4. Запустите сервер FastAPI:
   ```bash
   uvicorn main:app --host idp.test --port 443 --ssl-keyfile "idp.test+1-key.pem" --ssl-certfile "idp.test+1.pem" --reload
   ```
   *Документация API будет доступна по адресу: `https://idp.test/docs`*

### Шаг 3. Запуск Frontend (RP)
1. Откройте новый терминал в папке `frontend`.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Создайте файл `.env` в папке `frontend`:
   ```env
   VITE_API_URL=https://idp.test
   ```
4. Запустите React-сервер:
   ```bash
   npm run dev
   ```
   *Сайт будет доступен по адресу: `https://rp.test:5173`*

### Шаг 4. Тестирование
1. Откройте `https://idp.test/docs` и `https://rp.test:5173` в браузере и разрешите использование локального сертификата (Дополнительные -> Перейти на сайт).
2. На сайте `rp.test` пройдите регистрацию и авторизацию через синюю кнопку.
3. Вернитесь на главную страницу и нажмите зеленую кнопку **"Быстрый вход (FedCM)"** для демонстрации бесшовной аутентификации.
